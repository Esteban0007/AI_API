What is Semantic Search?

Semantic Search understands the intent and contextual meaning of a query rather than just matching literal keywords. By converting text into vector concept maps, the system identifies relationships, synonyms, and crosses languages instantly.

Feature Traditional Search (Lexical) Semantic Search (ReadyAPI)
Search Logic Matches exact characters/keywords. Understands intent and concepts.
Language Limited to document language. Multilingual: Search English, find Spanish.
Synonyms Fails unless words match exactly. Succeeds by meaning ("broken screen" = "my display is shattered and won't turn on").

See It in Action

A clean, streamlined example using 3 core system documents.

[01] Prepare Your JSON Payload

Send your data payload to the upload endpoint. ReadyAPI automatically generates embeddings under the hood. 

{
  "documents": [
    {
      "id": "part-001",
      "title": "Charge System",
      "content": "solar panels energy reactor battery charging power recharge fuel cells electricity",
      "metadata": {"state": "idle"}
    },
    {
      "id": "part-002",
      "title": "Flight System",
      "content": "thruster engine propulsion fly speed boost travel navigate rocket jet turbine",
      "metadata": {"state": "active"}
    },
    {
      "id": "part-003",
      "title": "Stealth System",
      "content": "cloak invisibility hide camouflage stealth radar ghost disappear vanish disguise",
      "metadata": {"state": "hidden"}
    }
  ]
}

[02] Natural Language Query

Query using natural human concepts (e.g., finding fast travel without mentioning exact words). 

curl -X POST https://readyapi.net/api/v1/search/query \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "I need to travel far away quickly",
    "top_k": 2
  }'
